# KV-MD Privacy Policy

KV-MD does not collect, store or transmit any personal data.

- No accounts, analytics, telemetry or crash reporting.
- Documents are read locally and never leave your Mac.
- The only network requests KV-MD makes are for **remote images referenced inside a document you open** (for example, badges in a README). They go directly to the server named in the document, exactly as a web browser would load them.
- Preferences (sidebar visibility, zoom level, window size) are stored locally in macOS user defaults.
